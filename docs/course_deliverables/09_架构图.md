### 图 9：YOLO-Pose 算法超参数动态热重载 (Hot-Reload) 调用链与线程安全时序图

```mermaid
sequenceDiagram
    autonumber
    actor Engineer as 运维工程师 (前端)
    participant UI as AlgorithmConfigModal (前端组件)
    participant Java as SVA-backend (Java 控制器)
    participant Server as C++ Server (HTTP 9993)
    participant Sched as C++ Scheduler (调度器)
    participant Worker as C++ Worker 线程池 (1..N)

    Engineer->>UI: 调节姿态与时序参数滑块
    Engineer->>UI: 点击【立即热加载】
    UI->>Java: POST /waring/algorithm/config/update (JSON Config)
    Java->>Java: 参数范围与布控范围校验
    Java->>Server: HTTP POST /api/control/update-algorithm-config
    Server->>Sched: updateAlgorithmConfig(controlCode, rule, thresholds)
    rect rgb(240, 248, 255)
        Note over Sched,Worker: 任务容器与运行布控容器互斥保护
        loop 遍历当前运行且启用睡岗规则的 Worker
            Sched->>Worker: worker->updateAlgorithmConfig(...)
        end
        Sched->>Sched: 实际任务更新成功后再修改共享 Pose 阈值
    end
    Worker-->>Sched: 返回 updatedControls
    Sched-->>Server: 返回 code=1000 与 globalThresholdsUpdated
    Server-->>Java: HTTP 200 (Analyzer code=1000)
    Java-->>UI: HTTP 200 (后端 code=200，附最近一次回执)
    UI-->>Engineer: 展示历史下发记录，实时状态标记为 UNVERIFIED
```

### 图 10：双路独立国标流媒体中继与电脑摄像头 WebM 转换流水线图

```mermaid
flowchart TD
    subgraph BrowserCapture["浏览器客户端 (Chrome / Edge)"]
        MediaDev["HTML5 navigator.mediaDevices.getUserMedia()"]
        Recorder["MediaRecorder API (MIME: video/webm;codecs=vp8/h264)"]
        WSClient["WebSocket 客户端 (ws://localhost:18090)"]
        MediaDev --> Recorder --> WSClient
    end

    subgraph ServerRelay["服务端中继网关 (webcam_bridge.py)"]
        WSServer["WebSocket 服务端监听 (:18090)"]
        PipedStdin["Linux FIFO / Anonymous Pipe 管道"]
        FfmpegTrans["FFmpeg 实时封装转换进程"]
        ColorBars["SMPTE 测试彩条自愈发生器 (testsrc2)"]

        WSClient -->|"WebM 二进制流"| WSServer
        WSServer -->|"实时写入"| PipedStdin
        PipedStdin --> FfmpegTrans
        WSServer -.->|"无数据超时 (3s)"| ColorBars
        ColorBars -.->|"自动切换兜底"| FfmpegTrans
    end

    subgraph MediaServerCore["ZLMediaKit 流媒体与国标接入网关"]
        RtmpIn["RTMP 接收器 (rtmp://127.0.0.1:9995/live/webcam)"]
        Dev2Sim["国标模拟器 (设备2: 34020000001320000003)"]
        SipChannel["SIP 信令通道 (UDP 15062 -> 5060)"]
        PsRtpPush["MPEG-PS / RTP 推流通道 (UDP -> 30002)"]
        ZlmRtp["ZLM RTP 国标流收流解复用器"]
        BridgeDaemon["gb_bridge_daemon.py 动态转桥守护"]
        FlvOut["HTTP-FLV 实时播放流 (http://127.0.0.1:9992/live/34020000001320000003.live.flv)"]

        FfmpegTrans -->|"RTMP 推流"| RtmpIn
        RtmpIn --> Dev2Sim
        Dev2Sim <-->|"注册保活/INVITE"| SipChannel
        Dev2Sim -->|"打包 PS-RTP"| PsRtpPush
        PsRtpPush --> ZlmRtp
        ZlmRtp --> BridgeDaemon
        BridgeDaemon --> FlvOut
    end

    subgraph ClientPlay["前端监视与 AI 分析"]
        WebPlayer["flv.js 实时监控窗格"]
        AiAnalyzer["C++ YOLO-Pose 姿态分析 Worker"]
        FlvOut --> WebPlayer
        FlvOut --> AiAnalyzer
    end
```
