## 三、 极速 3 步启动流程

> 请在 **Windows PowerShell**（管理员模式或普通用户均可）中执行以下命令：

### 第 1 步：进入部署包目录并导入镜像（仅需首次执行一次）
```powershell
cd "C:\Users\34964\Desktop\easySVA-部署包"
docker load -i easysva-images-v1.0.tar
```
*终端将输出多行 `Loaded image: easysva-xxx:1.0`、`Loaded image: mariadb:10.6`，看到完成提示后，通过 `docker images` 可见 7 个镜像。*

### 第 2 步：一键启动全部 7 大微服务
```powershell
docker compose up -d
```
*系统自动创建网络与存储卷，约 **30~60 秒** 全部微服务就绪。*  
*执行查看容器状态指令：*
```powershell
docker compose ps
```
*当所有容器状态显示为 `Up`（其中 `sva-mysql`、`sva-redis`、`sva-media` 显示 `healthy`）即代表全系统自愈就绪。*

### 第 3 步：浏览器打开系统
在 Chrome 或 Edge 浏览器直接访问：  
👉 **`http://localhost`** （端口 80，直接访问 localhost，无需添加 8080）
- **默认管理员账号**：`admin`
- **默认登录密码**：`admin123`
- **验证码**：已配置自动免验，直接点击【登录】即可进入系统！

## 六、 常见问题与排障指南 (FAQ)

### 6.1 本机 80 端口被占用怎么办？
告警抓拍图片由后端按标准 80 端口反代拼接。强烈建议释放 80 端口：
- **排查占用**：在 PowerShell 运行 `netstat -ano | findstr ":80 "`，获取最后一列的 PID，再通过 `tasklist | findstr <PID>` 查找占用进程。
- **常见占用**：Windows IIS 服务（W3SVC）、其他 Nginx 或 Apache。在【服务】（services.msc）中停止 World Wide Web Publishing Service 即可。

### 6.2 页面能打开但抓拍图不显示 / 裂图？
系统通过 `host.docker.internal` 让宿主机浏览器访问图片反代。若 Windows 本机未自动解析，请以管理员身份用记事本打开：  
`C:\Windows\System32\drivers\etc\hosts`，在末尾添加一行：
```text
127.0.0.1 host.docker.internal
```
保存后刷新浏览器即可正常显示。

### 6.3 电脑没有 NVIDIA 独立显卡能否运行？
**完全可以**。`sva-analyzer` 镜像内置自适应降级逻辑。当检测不到 GPU 时，会自动回退至 CPU 软件编码（`libx264`），日志中出现 `NVENC open failed, falling back to software H.264` 属于正常现象，睡岗算法与告警业务 100% 正常工作。

### 6.4 如何接入真实的第三方国标摄像机？
在平台【设备管理】中添加设备，真实摄像机配置指向宿主机 IP：
- **SIP 服务器 IP**：本机 IP，**SIP 端口**：`5060` (UDP)
- **SIP 域 (Realm)**：`3402000000`
- **服务器国标 ID**：`34020000002000000001`
- **注册密码**：`12345678`
- **RTP 收流端口**：`30002 ~ 30100` (UDP，请确保 Windows 防火墙已放行)

# 【第二篇】Linux / WSL 原生编译部署与运维手册（面向二次开发）

## 七、 源码工程编译与构建

### 7.1 基础工具链与中间件依赖
在 Ubuntu 22.04 LTS (或 WSL2) 下执行：
```bash
sudo apt-get update
sudo apt-get install -y build-essential cmake pkg-config git curl wget     openjdk-8-jdk mysql-server redis-server nginx ffmpeg     libopencv-dev libavcodec-dev libavformat-dev libavutil-dev     libswscale-dev libasound2-dev python3-pip
```

### 7.2 数据库与缓存初始化
```bash
# 设置 MySQL 密码
sudo mysql -e "ALTER USER 'root'@'localhost' IDENTIFIED WITH mysql_native_password BY 'easySVA.EZ'; FLUSH PRIVILEGES;"
# 创建库并导入 SQL
mysql -u root -peasySVA.EZ -e "CREATE DATABASE IF NOT EXISTS \`easySVA\` DEFAULT CHARACTER SET utf8mb4;"
mysql -u root -peasySVA.EZ easySVA < /opt/SVA-dev/SVA-backend/sql/ry_20210908.sql
mysql -u root -peasySVA.EZ easySVA < /opt/SVA-dev/SVA-backend/sql/easySVA.sql
```

### 7.3 四大子系统编译
1. **编译 ZLMediaKit 与 GbSipServer**：
   ```bash
   cd /opt/SVA-dev/SVA-backend/SVA-mediaServer
   mkdir -p build && cd build && cmake .. -DENABLE_GB28181=true && make -j$(nproc)
   ```
2. **编译 C++ SVA-server 推理服务**：
   ```bash
   cd /opt/SVA-dev/SVA-server
   mkdir -p build-dev && cd build-dev && cmake .. -DCMAKE_BUILD_TYPE=Release && make -j$(nproc)
   ```
3. **打包 Java SVA-backend 后端**：
   ```bash
   cd /opt/SVA-dev/SVA-backend/SVA-backend
   mvn clean package -DskipTests
   ```
4. **构建 Vue SVA-web 前端**：
   ```bash
   cd /opt/SVA-dev/SVA-web
   npm run build:prod
   ```

### 7.4 一键全栈自愈启动：`restart.sh`
运行系统运维脚本一键拉起原生全套服务：
```bash
sudo bash /opt/SVA-dev/restart.sh
```
脚本自动按拓扑依赖拉起 MediaServer、GbSipServer、双国标模拟器、Webcam中继、C++ Analyzer、Java 后端，并自动调用 `auto_recover.sh` 恢复历史布控任务。
