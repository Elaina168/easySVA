## 一、 系统登录与环境接入

1. **访问地址**：打开 Google Chrome 或 Microsoft Edge 浏览器，访问系统前端地址：  
   `http://127.0.0.1:80` 或 `http://127.0.0.1:8888`
2. **初始登录凭据**：
   - 用户名：`admin`
   - 初始密码：`admin123`
   - 验证码：输入右侧图片计算结果或验证码文本。
3. **进入系统**：点击【登录】按钮，系统将完成 JWT 身份鉴权并跳转至【首页数据大屏】。

## 二、 设备管理与国标一键同步

### 2.1 查看与筛选设备
- 导航路径：左侧菜单【设备管理】 $\rightarrow$ 【设备列表】。
- 列表支持按照设备类型（`GB28181 国标设备` / `RTSP 设备`）与在线状态进行标签化检索。

### 2.2 一键同步国标设备 (核心功能)
当外部有海康、大华摄像头或本地国标模拟器接入并完成 SIP 注册后：
1. 点击右上角蓝色按键【从流媒体同步国标设备】；
2. 系统后台将自动调用 GbSipServer 接口，秒级刷新设备列表；
3. 列表中将自动出现国标设备记录，状态显示为绿色的【在线】，国标编码与通道 ID 自动回显。

## 三、 实时监控工作台与九分屏监看

- 导航路径：左侧菜单【设备管理】 $\rightarrow$ 【实时监控】。

### 3.1 分屏切换与画面加载
1. **分屏比例调节**：在工作台顶部操作栏，点击【1 分屏】、【4 分屏】或【9 分屏】按钮，界面自适应调整视频网格布局。
2. **加载视频**：
   - 鼠标单击选择任意一个视频窗格（激活高亮蓝框）；
   - 在左侧设备树中点击指定的摄像头名称（如“西门高精度国标球机”）；
   - 系统将立即拉取低延迟 HTTP-FLV 流并实现毫秒级首帧秒开播放。
3. **全屏沉浸式监看**：点击顶部【全屏】按钮，监控墙自动撑满整个物理显示器，按下 `ESC` 键即可退出全屏。

## 四、 国标云台控制面板 (PTZ Control) 使用指南

在实时监控工作台顶部点击【云台控制 (PTZ)】按钮，右侧将平滑展开专业级深色科技感云台控制抽屉：

```
+----------------------------------------------------+
|               云台控制 (PTZ)                       |
+----------------------------------------------------+
| 当前窗口: [窗口 1] 西门高精度国标球机              |
| 协议类型: [GB28181 国标协议] | 缩放: 1.2x          |
+----------------------------------------------------+
|                                                    |
|                 ( 上仰: Up )                       |
|           (左上)     ^      (右上)                 |
|             <    [  STOP  ]   >                    |
|           (左下)     v      (右下)                 |
|                 ( 俯视: Down )                     |
|                                                    |
+----------------------------------------------------+
| 镜头拉伸 / 变焦：                                  |
| [ 放大 (+) ]     [ 缩小 (-) ]     [ 复位 (Reset) ] |
+----------------------------------------------------+
| 云台转速调节 (1-255)： [=====O=============] 32     |
+----------------------------------------------------+
| 国标协议指令回显 (GB/T 28181):                     |
| PTZCmd: A50F0108002000D7                           |
| 动作: 向上仰视 (Tilt Up) (速度: 32)                |
+----------------------------------------------------+
```

### 4.1 八向雷盘方向控制
- **单次微调**：点击圆盘上的【上、下、左、右、左上、右上、左下、右下】箭头按钮，摄像头向对应方向轻微转动一步；
- **连续旋转**：鼠标长按方向按钮不放，摄像头持续平滑旋转；鼠标松开后系统自动发送 `Stop` 制动指令；
- **紧急制动**：点击圆盘中心红色的【STOP】按钮，云台电机立即抱闸刹停。

### 4.2 镜头变焦与复位
- 点击【放大 (+)】：镜头推进放大细节，电子云台以当前画面中心进行 1.25x ~ 3.5x 无损数字特写放大；
- 点击【缩小 (-)】：镜头拉远缩小，扩展视野；
- 点击【复位】：视口平滑复位至原始全局视角（1.0x，X:0, Y:0）。

### 4.3 速度滑块与指令监控
- 拖动【云台转速】滑块（1~255 档），可动态调整机械转速与信令速度参数；
- 底部【国标协议指令回显】实时展现发送的 8 字节 Hex 码（如 `A50F0108002000D7`），便于协议审计与现场演示。

## 五、 工位睡岗布控与事件中心

### 5.1 创建睡岗布控任务
1. 导航至【布控管理】 $\rightarrow$ 【任务配置】 $\rightarrow$ 点击【新增布控】；
2. 选择待监控的国标或 RTSP 摄像头；
3. 算法类型下拉选择【工位睡岗检测 (YOLO-Pose)】；
4. **绘制工位敏感区 (ROI)**：在弹出的视频预览截图中，使用鼠标单击 4 个顶点绘制出工位座席多边形区域，屏蔽通道走动人员；
5. 设置持续时间阈值（推荐默认 5.0 秒），保存并启动任务。

### 5.2 告警中心与证据链审查
1. 导航至【告警管理】 $\rightarrow$ 【告警列表】；
2. 当值班人员发生长时睡岗时，系统将发出高危告警弹窗与警报提示；
3. 点击告警条目可查看抓拍的高清图片（含标注的人体 17 骨骼关键点连线与头部俯仰角计算结果）；
4. 业务人员可填写审核意见，点击【确认有效】或【误报剔除】完成闭环流转。

## 六、 运维专属：双专项终端监控大屏

运维工程师在调试与巡检时，可在服务器后台直接运行两个只读监控看板：

### 6.1 本机核心服务大屏
```bash
bash /opt/SVA/sva_monitor.sh
```
- 2 秒自动刷新，实时展示 Backend / ZLM / Analyzer / MySQL / Redis / Nginx 运行状态、进程 PID、活跃视频流数与 CPU/内存使用率。

### 6.2 国标协议信令大屏
```bash
bash /opt/SVA/gb_monitor.sh
```
- 实时展示国标设备在线存活状态、15 秒心跳倒计时进度条、点播 Session ID 以及收到的 PTZ 控制指令计数。
