## 五、 算法超参数在线动态调优实操指南 (Hot-Reload)

为了让算法能够自适应不同安装视角与工位距离，系统在实时监控页面提供了免重启热调优能力：

1. **打开调节面板**：进入【设备管理】 $
ightarrow$ 【实时监控】，在页面顶部工具栏点击 **【算法参数调节】** 按钮；
2. **多维滑块微调**：
   - **目标检出置信度** (`detectionConfidence`) 与 **NMS 阈值** (`nmsThreshold`) 作用于共享 Pose 模型；
   - **关键点置信度** (`keypointConfidence`)、**确认窗口** (`confirmWindowSec`)、**睡岗正样本比例** (`sleepPositiveRatio`) 控制判定灵敏度；
   - **头肩高度比** (`headHeightRatioMax`)、**头臂距离比** (`headArmDistanceRatioMax`)、**头部微动比** (`headMotionRatioMax`)、**躯干倾角** (`torsoAngleDegMin`) 和 **肩部倾斜角** (`shoulderTiltDegMin`) 适配机位姿态；
   - **苏醒恢复时间** (`recoveryMs`) 与 **运动统计窗口** (`motionWindowMs`) 控制时序稳定性。具体范围以弹窗从后端加载的滑块范围为准；
3. **应用生效**：点击弹窗右下角 **【立即热加载】**。`controlCode="*"` 更新全部运行且启用睡岗规则的布控，具体编号只更新该布控；后端会显示实际 `updatedControls` 回执；
   - 目标检出置信度和 NMS 是共享模型参数，只能在广播范围修改；无运行睡岗布控时请求会失败；
4. **配置生命周期**：热调只作用于当前运行 Analyzer，后端只保存最近一次下发记录，不代表引擎实时状态；重启 Analyzer 或重新启动布控后需要重新应用。

## 六、 工位电脑摄像头实景接入指南 (Webcam Live)

针对现场无实体安防摄像机的评测与演练场景，系统支持直接将笔记本/电脑自带摄像头虚拟为一台 GB28181 国标设备：

1. **开启摄像头**：点击页面顶部导航栏的 **【开启电脑摄像头】** 按钮；
2. **浏览器授权**：Chrome/Edge 会弹出权限请求：“是否允许使用摄像头”，点击【允许】；
3. **视频推流建立**：
   - 导航栏指示灯变绿，提示“电脑摄像头推流中 (18090)”；
   - 此时工位摄像头视频实时通过 WebSocket 发往中继服务，并被虚拟为**设备 2：工位实景国标摄像头（34020000001320000003）**；
4. **实景睡岗演练**：
   - 在实时监控工作台打开设备 2 画面；
   - 演示者在工位上趴在桌上模拟打瞌睡，数秒后即可触发真实的现场睡岗告警与抓拍！

## 七、 国标云台 PTZ 8 向与变焦控制实操指南

1. **调出控制盘**：在【实时监控】工作台中，选中支持 PTZ 的国标球机窗口，点击右侧侧边栏【云台控制】面板；
2. **全向旋转操作**：
   - 点击虚拟雷盘的 8 个方向（上、下、左、右、左上、右上、左下、右下），对应下发国标 8 字节控制信令；
   - 松开鼠标或点击中心按钮，设备自动停止转动（发送 Stop 指令）；
3. **变焦与转速微调**：
   - 点击【放大 (+)】或【缩小 (-)】控制镜头变倍拉伸；
   - 拖动【云台转速】滑块（1~255，默认 32），可精准控制电机旋转角速度；
4. **指令回显与反馈**：
   - 监控画面出现操作提示徽标（如“向上仰视 速度:32”）；
   - 右侧控制台实时打印生成的 8 字节国标 Hex 报文（如 `A50F0108002000D7`），便于答辩与技术验收展示。

## 九、 系统全景看板与国标信令监控实操（运维与评测指引）

在系统演示、答辩和日常排障时，无需同时打开多个终端查看日志，系统已内置两套全彩实时终端监控看板及一款抓包工具：

### 9.1 查看全系统健康看板：`sva_monitor.sh`
打开 Linux/WSL 终端输入：
```bash
bash /opt/SVA-dev/sva_monitor.sh
```
- **实时呈现**：全系统 6 大核心服务（ZLMediaKit、GbSipServer、C++ Analyzer、Java 后端、Nginx、MySQL）存活状态 `● OK`；后台关键进程 PID；当前运行中的布控任务；当前所有实时推拉流列表；系统负载与累计告警总数。
- **退出方式**：按 `Ctrl+C` 退出，纯只读不影响系统服务。

### 9.2 查看国标设备专项看板：`gb_monitor.sh`
在终端输入：
```bash
bash /opt/SVA-dev/gb_monitor.sh
```
- **实时呈现**：西门球机与电脑摄像头双设备注册状态、心跳衰减倒计时（超过 30s 自动变黄预警，超过 45s 标红判定离线）；当前活跃的 SIP 点播流 Session 与分配的媒体端口；累计信令统计与最新云台控制动作。

### 9.3 云台控制信令实时抓包：`ptz_capture.sh`
在终端输入：
```bash
bash /opt/SVA-dev/ptz_capture.sh
```
终端进入监听状态。此时在前端网页点击云台方向按钮，终端即可毫秒级抓取对应的 UDP 报文并打印解码结果（原始报文、方向动作、水平/垂直速度、Checksum 校验码），是国标云台控制答辩验收的极佳佐证。
