# easySVA 安全视频分析平台 - 交付工程文档全景索引 (Docs Index)

欢迎查阅 **easySVA (easy Surveillance Video Analytics)** 系统的全套软件工程交付文档。  
本套文档严格依照国家标准软件工程交付规范（GB/T 8567-2006）与大三软件工程实训课程《企业应用设计实践》（Hackathon 敏捷实战，指导教师：吴军、孙溢）的 4 阶段验收指标编制，全面记录了原生平台环境搭建、国标 GB/T 28181 接入、YOLO-Pose 睡岗检测、GB28181 云台控制（PTZ）、自适应流媒体优化以及终端运维大屏的设计与落地成果。
