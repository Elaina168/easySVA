## 二、 专项深度测试用例与执行记录

### 2.1 [TC-ALGO-04] YOLO-Pose 参数在线热更新测试
- **测试目的**：验证修改置信度、夹角阈值及连续帧数时，C++ Analyzer 无需重启且即刻生效。
- **执行过程**：
  1. 调用 `POST /waring/algorithm/config/update` 将 `sleep_frame_threshold` 从 125 改为 50，`sleep_torso_angle_thresh` 改为 35°；
  2. 观察 C++ 控制台输出：`[Config] Algorithm config updated: torso_thresh=35.0, frame_thresh=50`；
  3. 推送瞌睡视频，原本需要 5 秒确诊的睡岗行为在 2 秒（50帧）即产生告警；
  4. 检查视频播放器，画面无黑屏、无解码器重置、无卡顿。
- **测试结果**：**PASS**。

### 2.2 [TC-PTZ-01] GB28181 云台八向旋转与变焦指令下发与抓包测试
- **测试目的**：验证前端八向虚拟雷盘下发的指令符合 GB/T 28181-2016 规范。
- **执行过程**：
  1. 在网页端点击【向上】按钮（速度 32）；
  2. 后端生成 8 字节 Hex：`A5 0F 01 08 00 20 00 D7`；
  3. 执行 `bash ptz_capture.sh` 抓包，抓取到对应 SIP MESSAGE 并成功解码：  
     `动作=向上俯仰 (Tilt Up), 垂直速度=32, 校验和=D7 (正确)`；
  4. 模拟器端打印日志：`[PTZ] 执行向上俯仰` 并回送 200 OK。
- **测试结果**：**PASS**。

### 2.3 [TC-DOCKER-01] Docker Desktop 7 大微服务一键启动与全链路验证
- **测试目的**：验证纯净 Windows 环境无任何开发依赖下，仅通过 Docker Desktop 能否跑通全业务。
- **执行过程**：
  1. 在 PowerShell 执行 `docker load -i easysva-images-v1.0.tar`；
  2. 执行 `docker compose up -d`，35 秒后 7 个容器全部 Up；
  3. 打开 `http://localhost`，使用 `admin/admin123` 登录成功；
  4. 启动 `gbsleep001` 布控，进入实时监控，看到带骨骼线的瞌睡视频并顺利弹出告警与抓拍图。
- **测试结果**：**PASS**。
