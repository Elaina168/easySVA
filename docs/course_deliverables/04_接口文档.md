## 一、 接口设计通则与规范

1. **通信协议**：HTTP/1.1、RESTful API 架构风格。
2. **字符编码**：UTF-8。
3. **鉴权机制**：基于 HTTP Header `Authorization: Bearer <token>` 传递 JWT 认证凭据。
4. **统一响应格式**：
```json
{
  "code": 200,
  "msg": "操作成功",
  "data": {}
}
```
- `code`: 状态码，`200` 代表成功，`401` 代表凭证无效，`500` 代表业务或系统异常。
- `msg`: 文本提示信息。
- `data`: 业务负载对象或数组。

## 二、 设备管理接口族 (Device APIs)

### 2.1 分页查询设备列表
- **接口地址**：`GET /waring/device/list`
- **接口说明**：支持按照设备名称、设备类型（RTSP / gb28181）、在线状态进行组合筛选与分页查询。
- **请求参数**：
  | 参数名 | 类型 | 必填 | 描述 |
  | :--- | :---: | :---: | :--- |
  | `pageNum` | Integer | 否 | 页码（默认 1） |
  | `pageSize` | Integer | 否 | 每页条数（默认 10） |
  | `name` | String | 否 | 设备名称模糊匹配 |
  | `deviceType`| String | 否 | 设备类型：`rtsp` 或 `gb28181` |
  | `status` | String | 否 | 在线状态：`1`在线，`0`离线 |
- **响应示例**：
```json
{
  "total": 1,
  "rows": [
    {
      "id": 1,
      "ape_id": "gb_34020000001320000002_0100000016",
      "name": "西门高精度国标球机",
      "device_type": "gb28181",
      "ip": "127.0.0.1",
      "port": 15060,
      "gb_device_id": "34020000001320000001",
      "gb_channel_id": "34020000001320000002",
      "play_url": "http://127.0.0.1:9992/live/gb_34020000001320000002_0100000016.live.flv",
      "status": "1",
      "create_time": "2026-09-08 10:20:00"
    }
  ],
  "code": 200,
  "msg": "查询成功"
}
```

### 2.2 从流媒体服务同步国标设备
- **接口地址**：`POST /waring/device/sync`
- **接口说明**：调用此接口触发后端向 GbSipServer 发起查询，将已向平台注册的所有 GB28181 在线设备与通道自动录入或更新到本地 `h_device` 数据表，并刷新在线状态。
- **请求参数**：无请求体。
- **响应示例**：
```json
{
  "code": 200,
  "msg": "国标设备同步完成，共处理 1 台",
  "data": 1
}
```

### 2.3 GB28181 国标云台控制 (PTZ Control) [NEW]
- **接口地址**：`POST /waring/device/ptz/{apeId}`
- **接口说明**：向指定国标设备发送云台旋转、镜头拉伸变焦或停止刹车指令。后端自动计算 8 字节 Hex 指令码并发送 SIP MESSAGE 报文。
- **路径参数**：`apeId`（设备唯一标识）
- **请求体 (JSON)**：
  | 字段名 | 类型 | 必填 | 取值范围与说明 |
  | :--- | :---: | :---: | :--- |
  | `command` | String | 是 | `up`, `down`, `left`, `right`, `upleft`, `upright`, `downleft`, `downright`, `zoomin`, `zoomout`, `stop`, `reset` |
  | `speed` | Integer | 否 | 云台旋转/变焦速度：`1 ~ 255`（默认 `32`） |
- **请求体示例**：
```json
{
  "command": "up",
  "speed": 32
}
```
- **响应示例**：
```json
{
  "code": 200,
  "msg": "云台控制指令已下发",
  "data": {
    "apeId": "gb_34020000001320000002_0100000016",
    "command": "up",
    "speed": 32,
    "ptzCmd": "A50F0108002000D7",
    "action": "向上仰视 (Tilt Up)"
  }
}
```

## 三、 布控任务管理接口族 (Task APIs)

### 3.1 创建睡岗/安全布控任务
- **接口地址**：`POST /waring/task`
- **请求体 (JSON)**：
```json
{
  "task_name": "主监控室值班员睡岗布控",
  "ape_id": "gb_34020000001320000002_0100000016",
  "algorithm_type": "sleep_pose",
  "roi_polygon": "[[100, 150], [500, 150], [500, 480], [100, 480]]",
  "threshold": 5.0,
  "status": 1
}
```
- **响应示例**：
```json
{
  "code": 200,
  "msg": "布控任务创建成功",
  "data": { "taskId": 12 }
}
```

### 3.2 启停布控任务
- **接口地址**：`PUT /waring/task/status`
- **请求体**：
```json
{
  "task_id": 12,
  "status": 1
}
```

## 四、 实时告警与事件接口族 (Alarm APIs)

### 4.1 C++ 分析器上报睡岗告警事件
- **接口地址**：`POST /waring/alarm/upload`
- **请求协议**：Multipart Form Data
- **请求参数**：
  | 字段名 | 类型 | 说明 |
  | :--- | :---: | :--- |
  | `ape_id` | String | 触发设备标识 |
  | `task_id` | Long | 触发任务 ID |
  | `alarm_type`| String | 固定为 `sleep_pose`（睡岗） |
  | `confidence`| Float | 姿态检测置信度（如 `0.94`） |
  | `duration` | Float | 持续低头睡岗时长（秒，如 `5.2`） |
  | `snapshot` | Binary | 现场告警抓拍图像 (JPEG 格式) |
  | `video_clip`| Binary | (可选) 前后 10 秒证据视频文件 |
- **响应示例**：
```json
{
  "code": 200,
  "msg": "告警入库成功",
  "data": { "alarmId": 1082 }
}
```

### 4.2 告警审核与误报处理
- **接口地址**：`PUT /waring/alarm/handle`
- **请求体**：
```json
{
  "alarm_id": 1082,
  "handle_status": 2,
  "handle_remark": "经人工复核，为夜间脱岗打瞌睡，已电话通知提醒"
}
```

## 五、 算法流按需节能接口族 (Stream Control)

### 5.1 激活算法推流 (无人观看自动休眠机制)
- **接口地址**：`POST /waring/stream/active`
- **请求体**：`{ "apeId": "gb_34020000001320000002_0100000016" }`
- **说明**：前端用户在实时监控页面加载视频时调用，服务端激活 C++ 分析器画框并开启 RTMP/FLV 转发推流。

### 5.2 休眠算法推流
- **接口地址**：`POST /waring/stream/deactive`
- **请求体**：`{ "apeId": "gb_34020000001320000002_0100000016" }`
- **说明**：前端用户关闭窗格或切换页面离开时调用，关闭编码画框推流，大幅降低 GPU/CPU 负载。
