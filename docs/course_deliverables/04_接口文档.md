## 一、 接口设计通则与规范

1. **通信协议**：HTTP/1.1、RESTful API 架构风格。
2. **字符编码**：UTF-8。
3. **鉴权机制**：基于 HTTP Header `Authorization: Bearer <token>` 传递 JWT 认证凭据。
4. **统一响应格式**：
```json
{
  "code": 200,
  "msg": "操作成功",
  "data": {}
}
```
- `code`: 状态码，`200` 代表成功，`401` 代表凭证无效，`500` 代表业务或系统异常。
- `msg`: 文本提示信息。
- `data`: 业务负载对象或数组。

## 二、 设备管理接口族 (Device APIs)

### 2.1 分页查询设备列表
- **接口地址**：`GET /waring/device/list`
- **请求参数**：`pageNum` (页码), `pageSize` (每页条数), `deviceName` (名称检索), `streamSourceType` (`DIRECT`/`GB28181`), `isOnline` (`0`/`1`)。

### 2.2 从流媒体同步国标设备
- **接口地址**：`POST /waring/device/gb28181/sync`
- **说明**：触发后端调用 GbSipServer 获取当前注册的国标设备列表，去重写入数据库。
- **响应示例**：
```json
{
  "code": 200,
  "msg": "同步国标设备成功",
  "data": {
    "totalSynced": 2,
    "inserted": 0,
    "updated": 2
  }
}
```

### 2.3 国标云台 PTZ 控制接口
- **接口地址**：`POST /waring/device/ptz/{apeId}`
- **说明**：向指定国标设备下发 8 字节云台控制信令。
- **请求 Body**：
```json
{
  "command": "up",
  "speed": 32
}
```
- **字段说明**：
  - `command`: 控制动作，支持 `up`, `down`, `left`, `right`, `upleft`, `upright`, `downleft`, `downright`, `zoomin`, `zoomout`, `stop`, `reset`。
  - `speed`: 速度档位（1~255）。
- **响应示例**：
```json
{
  "code": 200,
  "msg": "PTZ指令已下发",
  "data": {
    "ptzCmd": "A50F0108002000D7",
    "command": "up",
    "speed": 32
  }
}
```

## 四、 算法参数在线动态热重载接口族 (Hot-Reload APIs)

### 4.1 查询当前算法超参数配置
- **接口地址**：`GET /waring/algorithm/config`
- **调用方**：前端「算法参数调节」弹窗打开时调用。
- **响应示例**：
```json
{
  "code": 200,
  "msg": "查询成功",
  "data": {
    "person_prob_threshold": 0.35,
    "keypoint_threshold": 0.40,
    "iou_threshold": 0.45,
    "sleep_torso_angle_thresh": 45.0,
    "sleep_hip_knee_angle_thresh": 50.0,
    "sleep_frame_threshold": 75
  }
}
```

### 4.2 在线热更新算法超参数配置
- **接口地址**：`POST /waring/algorithm/config/update`
- **调用方**：前端「算法参数调节」弹窗点击【应用生效】时调用。
- **请求 Body**：
```json
{
  "person_prob_threshold": 0.40,
  "keypoint_threshold": 0.45,
  "iou_threshold": 0.45,
  "sleep_torso_angle_thresh": 40.0,
  "sleep_hip_knee_angle_thresh": 55.0,
  "sleep_frame_threshold": 80
}
```
- **响应示例**：
```json
{
  "code": 200,
  "msg": "算法参数热更新成功",
  "data": {
    "updatedAt": "2026-09-10 17:20:00",
    "affectedWorkers": 2
  }
}
```

### 4.3 C++ Analyzer 核心控制接口
- **接口地址**：`POST http://127.0.0.1:9993/api/control/update_algorithm_config`
- **说明**：Java 后端透传至 C++ 分析引擎，实现无锁/读写锁实时分发。
- **响应示例**：
```json
{
  "code": 0,
  "msg": "success"
}
```
