## 三、幂等性说明

国标设备同步按 `gb_device_id` 判断：不存在则 INSERT，存在则 UPDATE（名称/在线状态/播放地址），重复同步不会产生重复设备；并发插入由 `uk_gb_device_id` 唯一索引兜底，捕获到唯一键冲突后先按 `gb_device_id` 复查，确认存在重复记录才按更新处理，查不到则视为真实插入失败并记录错误。

## 四、自动化验证脚本

`docs/test/verify_task4.sh` 为可重复执行的后端验证脚本，覆盖登录、RTSP 回归、同步接口、离线同步、幂等、睡岗告警入库/查询、GB 启动监控、ZLM 请求失败保留状态共 10 项断言，任一步失败以非 0 退出码结束。数据库密码通过环境变量 `MYSQL_PASSWORD` 传入。

## 五、数据库增量迁移

`docs/sql/alter_h_device.sql` 为幂等增量迁移（MariaDB 10.6+，使用 `ADD COLUMN IF NOT EXISTS` / `CREATE UNIQUE INDEX IF NOT EXISTS`），可重复执行；唯一索引创建前建议先检查存量重复 `gb_device_id`（见脚本内注释），存在重复需先清理。
